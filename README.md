# artistjoanmullins

artistjoanmullins.com is printed on Joan Mullins's cards. This tiny GitHub Pages site exists only to send anyone who visits it, on any page and over http or https, straight to her website at https://joanmullinsart.co.uk.

- `index.html` and `404.html` are the same page: an immediate redirect (meta refresh and script), with a plain link for anyone whose browser blocks both, a canonical link to the new address, and a request that search engines don't list this one.
- `CNAME` holds artistjoanmullins.com. The domain is in Steph's Namecheap account, pointed at GitHub Pages with the same address records as joanmullinsart.co.uk.

Nothing here needs updating. The main site lives in ewspartnership/joanmullinsart.
